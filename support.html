常見問題

如何連線到我的 Mac？

1. 在 Mac 上開啟「系統設定」→「一般」→「共享」→ 啟用「螢幕共享」。

2. 記下 Mac 的 IP 位址（可在「系統設定」→「網路」中查看）。

3. 在 VNC Pad 中輸入 IP 位址和 VNC 密碼即可連線。

如何啟用注音/拼音/日文輸入法支援？

您需要在 Mac 上安裝 VNCRemoteHelper。請參閱 Helper 安裝教學。

連線後畫面很模糊怎麼辦？

VNC Pad 會根據網路狀況自動調整畫質。如果網路穩定但畫面仍然模糊，請嘗試在設定中手動選擇「高品質」模式。

外接鍵盤的快捷鍵沒有反應？

請確認已安裝 VNCRemoteHelper 並已授予「輔助使用」權限。詳見 Helper 安裝教學。

可以透過網際網路連線嗎？

VNC Pad 設計為區域網路使用。如需透過網際網路連線，建議使用 VPN 將兩端設備置於同一虛擬網路中。

Mac 改了密碼之後連不上？

VNC Pad 1.1.1 起會偵測到密碼被拒絕，自動移除已儲存的舊密碼並立即要求輸入新密碼。也可以長按「已儲存」中的連線，選擇「忘記已儲存的密碼」。

Helper 的 PIN 碼輸入幾次後就連不上？

Helper 1.1.1 在連續輸入錯誤 5 次後會鎖定該裝置 60 秒，並自動更換 PIN。請點擊 Mac Menu Bar 的 Helper 圖示查看目前的 PIN。同一次使用期間 PIN 只需輸入一次；切換 App 或 Mac 睡眠後會自動以原 PIN 重連。

按住鍵不會重複、捲動很慢？

請將 VNC Pad 與 VNC Pad Helper 都更新到 1.1.1。按住鍵連續重複、像素級平滑捲動、Helper 模式下的雙擊都是在這個版本加入的。

系統需求

  • 目標 Mac 需啟用「螢幕共享」
  • 兩台裝置需在同一區域網路

Frequently Asked Questions

How do I connect to my Mac?

1. On your Mac, go to System Settings → General → Sharing → enable Screen Sharing.

2. Note your Mac's IP address (found in System Settings → Network).

3. Enter the IP address and VNC password in VNC Pad to connect.

How do I enable CJK input method support?

You need to install VNCRemoteHelper on your Mac. See the Helper Setup Guide.

The screen looks blurry after connecting?

VNC Pad automatically adjusts quality based on network conditions. If your network is stable but the image is still blurry, try manually selecting "High Quality" mode in settings.

External keyboard shortcuts not working?

Make sure VNCRemoteHelper is installed and has Accessibility permissions enabled. See the Helper Setup Guide.

Can I connect over the internet?

VNC Pad is designed for local network use. For internet access, we recommend using a VPN to place both devices on the same virtual network.

I changed my Mac's password and VNC Pad can't connect anymore?

Since version 1.1.1, VNC Pad detects a rejected password, removes the saved one and asks you for the new password right away. You can also long-press a saved connection and choose "Forget Saved Password".

The Helper PIN stops working after several wrong attempts?

Helper 1.1.1 locks a device out for 60 seconds after five consecutive wrong attempts and generates a new PIN. Click the Helper icon in the Mac menu bar to see the current PIN. During a session the PIN is asked only once; reconnects after app switching or Mac sleep reuse it automatically.

Held keys don't repeat, or scrolling is very slow?

Update both VNC Pad and VNC Pad Helper to 1.1.1. Key repeat for held keys, pixel-smooth trackpad scrolling and double-click in Helper mode were added in that release.

  • Both devices on the same local network
  • External keyboard recommended for best experience
  • Input method support requires VNC Pad Helper on the Mac (macOS 13 or later)
